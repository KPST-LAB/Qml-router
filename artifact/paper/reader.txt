//------------------------------------------------------------
// qml-router : one log per reported number, plus the inputs of every run
//   "Persistent Session-State Management for LLM Serving:
//    An Identity-Keyed Architecture for Durable, Engine-Agnostic Sessions"
// Purpose : verification. A reader opens logs/<name>.log to see the run that
//           produced a number, and data/ to see exactly what was sent to the
//           engines. The source code is released upon publication at
//           https://github.com/KPST-LAB/Qml-router.
// Layout  : logs/<name>.log   the client result log of one run (engine server
//                             logs, where kept, as <name>_srv.log.gz)
//           logs/<name>.json  runs whose result is a JSON file (Fig. 1(c))
//           data/             the inputs (prompts, planted facts, questions, gold
//                             answers) and result files, one file per experiment
//           scripts/          the scripts that produced each log (scripts/bin:
//                             the bench programs they call)
//           reader.txt        this file; one block per log: the run conditions
//                             ("run"), where the number is in the log (".log")
//           VERSIONS.txt      which log, script and data file stand behind each
//                             table and figure
// Names   : <table|figure|section id>_<experiment>_<condition>; no bench-internal
//           abbreviations in file names (tags inside the logs are explained per block).
// Merged  : when one run wrote several result files they are concatenated
//           into the one .log; each part starts with "#### file: <original>".
// Paths   : masked. $REPO repository root, $BENCH benchmark store root,
//           $DATA model/data root (H200), $HOME user home, $SCRATCH session
//           scratch dir, $NVME_MOUNT NVMe mount point, <host-ip> LAN address.
// Labels  : the bench clients print their result labels in Korean; the copies
//           here carry the same lines with English labels (numbers, order,
//           and line counts unchanged; the untouched originals stay on the
//           measurement hosts and in the repository history).
// Not here: Table 10 (mixed workload A/B/C) and the baseline-vLLM row of
//           Table 11 -- only engine server logs of those runs survive; the
//           counts are taken from docs/4-engines/engine-comparison.md.
//------------------------------------------------------------

//  [tag] ... total T s  R turn/s  overall p50 P ms  GPU prefill total K  correct a/b
