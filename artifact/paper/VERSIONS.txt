"Persistent Session-State Management for LLM Serving: An Identity-Keyed Architecture for
Durable, Engine-Agnostic Sessions" (IEEE Access, Access-2026-45930). Logs are in logs/,
scripts in scripts/ (bench programs in scripts/bin/), inputs and result files in data/.
"LME data" means the files in data/longmemeval/. reader.txt gives the run conditions of
each log and where the number is in it.

Engine versions behind every number: llama.cpp build b10141 (upstream 0d47ea742) with the
qml-router patch series, vLLM 0.26.0, SGLang 0.5.16, LMCache 0.5.2 (Table 15).
